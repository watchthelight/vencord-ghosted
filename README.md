# Ghosted has moved

This plugin now lives in [watchthelight/bash-plugins](https://github.com/watchthelight/bash-plugins) together with the rest of Bash's Vencord plugins, with a one line installer and updates from inside Discord. This repo is kept only for its history and will not receive changes.

If you cloned this repo into `src/userplugins/ghosted`, delete that folder and follow the install steps in the new repo.
